# Searqon Product Charter

## Product definition

Searqon by Tinlance is an evidence-first AI Discoverability and Agent Readiness Intelligence toolkit. It helps organizations understand whether digital properties can be discovered, interpreted, represented accurately, cited, and safely used by search systems, answer systems, generative AI systems, and authorized software agents.

**Tagline:** Be discovered. Be understood. Be actionable.

## Disciplines

- **SEO:** crawlability, indexability, information architecture, content quality, structured data, and technical search foundations.
- **AEO:** answer extraction, entity clarity, question coverage, source quality, and answer-oriented content structure.
- **GEO:** measured representation, mentions, citations, source attribution, and visibility across explicitly identified generative systems.
- **AgEO:** machine and agent readiness across discovery, interface documentation, protocol interoperability, authentication clarity, authorization boundaries, operational reliability, and transaction safety. AgEO is Searqon's proposed product discipline; it must not be presented as an established universal standard.

Each discipline has its own methodology, evidence, confidence, and result. Searqon must not collapse them into an unexplained universal score.

## Core operating loop

1. Establish a baseline and declare scope.
2. Collect bounded observations through documented methods.
3. Preserve source provenance and methodology versions.
4. Assess observations using versioned rules.
5. Produce prioritized, evidence-backed recommendations.
6. Reassess to verify changes.
7. Monitor only through authorized, documented observation methods.

## Initial product scope

The first useful release is a passive Agent Readiness Scanner plus a reusable evidence and assessment foundation. It may inspect public website pages, public documentation, published OpenAPI descriptions, and publicly advertised MCP metadata. It must not invoke discovered MCP tools, perform transactions, bypass authentication, or conduct unrestricted active probing.

GEO monitoring follows after the observation and evidence model is proven. Search and answer optimization features expand only after the core measurement methodology is validated with customers.

## Intended users

- API-first SaaS companies
- AI infrastructure and agent platform teams
- Developer-tool and MCP providers
- Technical SEO and digital agencies serving these organizations

## Product quality bar

A finding is actionable only when its evidence, observation class, timestamp, scope, confidence, and methodology version are available. A recommendation must state why it matters, what change is proposed, and how the change can be verified.

Searqon must distinguish observed facts, model-generated interpretations, derived metrics, and estimates. It must not imply guaranteed rankings, citations, recommendations, or agent adoption.

## Commercial model

The public Apache-2.0 toolkit should be independently useful. A future hosted offering may charge for managed monitoring, collaboration, scale, historical intelligence, benchmarking, governance, and service-level commitments. Pricing and gross-margin assumptions remain hypotheses until validated through interviews and paid pilots.

## Non-goals for initial release

- Executing tools on discovered MCP servers
- Authenticated penetration testing or unrestricted security scanning
- Scraping consumer AI products in ways that violate access terms
- Guaranteeing search rankings or model citations
- Replacing general-purpose web acquisition, agent orchestration, or sales automation systems
