# Support

Searqon is an early-alpha open-source toolkit. Support is provided on a best-effort basis; there is no paid support plan or service-level agreement for this repository.

## Where to ask

| Need | Where to go |
|---|---|
| Bug or reproducible defect | [Open a bug report](https://github.com/LloydCoder/tinlance-searqon/issues/new?template=bug_report.yml) |
| Feature proposal | [Open a feature request](https://github.com/LloydCoder/tinlance-searqon/issues/new?template=feature_request.yml) |
| Usage question | [GitHub Discussions](https://github.com/LloydCoder/tinlance-searqon/discussions) if enabled; otherwise open an issue with the `question` label |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not use public issues |
| Documentation correction | Open an issue or submit a focused pull request |

## Before asking

1. Read the [README](README.md) and [documentation index](docs/README.md).
2. Check the [scanner contract](docs/SCANNER.md) for supported inputs and known limitations.
3. Include the Searqon commit or package version, Node.js version and operating system.
4. Provide the smallest reproducible example possible.
5. Remove tokens, credentials, personal information and customer data.

## What support does not include

The project does not currently offer hosted monitoring, provider account troubleshooting, guaranteed response times, managed deployments or security certification. Do not send credentials or private customer content in an issue.
