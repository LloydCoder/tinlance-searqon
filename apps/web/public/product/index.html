FOUR DISTINCT DISCIPLINES

Different surfaces need
different measurements.

01 / SEO

Search foundations

Inspect technical discovery, indexability, document structure, metadata and foundational search signals from supplied documents or an explicitly authorized page.

02 / AEO

Answer readiness

Assess answer structure, question coverage, entity clarity and source-oriented content signals. Findings describe the tested document, not guaranteed answer-engine inclusion.

03 / GEO

Generative visibility

Normalize supplied AI-system observations, organize prompt cohorts, prepare bounded sampling plans and compare evidence-backed mention and citation changes.

04 / AgEO

Agent discoverability

Passively inspect machine-readable documentation, OpenAPI contracts and supplied MCP metadata without invoking tools or treating discovery as authorization.

WHAT EXISTS TODAY

Useful now.
Honest about limits.

01

Local assessment engine

Deterministic analysis of HTML, Markdown, OpenAPI JSON and caller-supplied MCP snapshots through the CLI and local web interface.

02

Evidence and provenance

Versioned evidence records, local integrity ledger, detached checkpoints and retention, redaction and legal-hold controls with documented custody limits.

03

GEO analysis and alerts

Registry-relative observations, cohort aggregation, citation-change detection and signed event contracts for supplied data. Live provider collection and outbound delivery are not yet available.

04

Early workspace foundation

Passwordless authentication, PostgreSQL-backed organizations, projects and persisted assessments are implemented in the repository. Public hosted-service acceptance remains open.

No universal visibility score.

Searqon does not collapse unlike signals into a magic number. Coverage, evidence class, confidence, methodology and limitations remain visible. The marketing dashboard is illustrative, not customer data.
